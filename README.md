# tuwebpronto.com

Sitio estático de TuWebPronto, publicado en Netlify.

- `index.html` — página principal
- `ejemplos/` — páginas de ejemplo por giro
- `legal/` — aviso de privacidad, términos y cookies
- `posts/` — imágenes de las publicaciones de Instagram/Facebook (n8n las publica desde `https://tuwebpronto.com/posts/...`)

No subir claves, tokens ni archivos `.env` a este repositorio.
